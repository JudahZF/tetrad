# tetrad-assets

Visual assets for `tetrad-ui`: the stock colour tokens, the IBM Plex Sans font and owned line
icons. The font is compiled in and rasterized at run time. No image, icon or font byte from the
unit is in this crate.

The fonts in `fonts/ibm-plex-sans/` are IBM's official release, unmodified, under the SIL Open
Font License 1.1 (`OFL.txt`). See the README in that folder.

Part of [Tetrad](../../README.md).
