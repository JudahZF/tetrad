# tetrad-media

Stock media: IR decoding (WAV, raw words and device-bound factory files), the factory IR
catalog, IR Loader and cab block transfer plans with the host cab blend, user IR products,
metronome sounds, owned offline convolution and the capture store re-encryption. Callers inject
bytes, key material and readers. No file system or device I/O.

Part of [Tetrad](../../README.md).
