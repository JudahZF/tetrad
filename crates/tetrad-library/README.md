# tetrad-library

The preset library.

- `stock::StockLibrary` reads and writes the stock CorOS library on the unit in place: setlists,
  presets, favourites, recents, searches, media folders and backups.
- `PresetLibrary` is a lossless editor over an owned SQLite format (`tetrad-storage`).
- `sidecar`: the JSON sidecar files next to each preset.

Part of [Tetrad](../../README.md).
