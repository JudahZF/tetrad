# tetrad-core

Shared rules that several crates use:

- `conversion`: stored value to display value, steps, defaults and display text.
- `performance`: scenes, stomps, footswitch modes, expression and the LED view.
- `workflow`: scene and parameter edits, and the preset lifecycle.
- `comparison`: typed comparison of preset states.

No I/O and no timers live here.

Part of [Tetrad](../../README.md).
