Backup

A backup holds the presets, setlists, IRs, captures, plugins and settings of the unit, as a cloud backup does. Tetrad's own settings (themes, mappings, footswitch modes) are not in it.

Download

The unit packs a backup, then your browser saves it as one .tar.gz file.

Restore

Send a backup file to the unit. Nothing changes before you touch RESTORE on the unit. The restore replaces the presets, IRs, captures and settings, then the unit reloads.
